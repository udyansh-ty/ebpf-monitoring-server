## Authentication

### Overview

All endpoints except `/health` require JWT Bearer token authentication. Tokens are obtained via the login endpoint and can be refreshed using the refresh endpoint.

**Token Lifespan:**
- Access Token: 24 hours (configurable via `JWT_TOKEN_EXPIRY`)
- Refresh Token: 7 days (configurable via `JWT_REFRESH_EXPIRY`)

### Authentication Header

```
Authorization: Bearer <access_token>
```

### Login Endpoint

**POST** `/api/auth/login`

Request authentication tokens using username and password.

**Request Headers:**
```
Content-Type: application/json
```

**Request Body:**
```json
{
  "username": "user",
  "password": "password"
}
```

**Response (200 OK):**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_at": "2025-02-10T07:47:00Z"
}
```

**Response Fields:**
- `access_token` (string): Token to include in `Authorization: Bearer` header
- `refresh_token` (string): Token used to refresh expired access tokens
- `token_type` (string): Always "Bearer"
- `expires_at` (RFC3339 timestamp): When access_token expires

**Error Responses:**
- `400 Bad Request`: Invalid username or password
- `400 Bad Request`: Missing username or password field

**Example:**
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user","password":"password"}'
```

### Refresh Token Endpoint

**POST** `/api/auth/refresh`

Obtain a new access token using a refresh token.

**Request Headers:**
```
Content-Type: application/json
```

**Request Body:**
```json
{
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**Response (200 OK):**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_at": "2025-02-10T07:47:00Z"
}
```

**Error Responses:**
- `401 Unauthorized`: Invalid or expired refresh token
- `400 Bad Request`: Missing refresh_token field

**Example:**
```bash
curl -X POST http://localhost:8080/api/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."}'
```

## Core Endpoints

### Health Check

**GET** `/health`

Check if the server is running and healthy. This endpoint does NOT require authentication.

**Response (200 OK):**
```json
{
  "service": "ebpf-server",
  "status": "healthy",
  "version": "v2.0"
}
```

**Response Fields:**
- `service` (string): Service name
- `status` (string): Current status ("healthy", "degraded", or "unhealthy")
- `version` (string): Server version

**Example:**
```bash
curl http://localhost:8080/health
```

## Program Management

### List Programs

**GET** `/api/programs`

List all active eBPF programs and their status.

**Authentication:** Required (Bearer token)

**Response (200 OK):**
```json
{
  "programs": [
    {
      "name": "connection_tracer",
      "status": "running",
      "event_count": 1524,
      "description": "Monitors network connections",
      "version": "1.0"
    },
    {
      "name": "packet_drop_monitor",
      "status": "running",
      "event_count": 89,
      "description": "Monitors packet drops",
      "version": "1.0"
    }
  ]
}
```

**Response Fields:**
- `programs` (array): List of program objects
  - `name` (string): Program identifier
  - `status` (string): "running", "stopped", or "error"
  - `event_count` (integer): Total events generated by program
  - `description` (string): Human-readable program description
  - `version` (string): Program version

**Example:**
```bash
curl http://localhost:8080/api/programs \
  -H "Authorization: Bearer $TOKEN"
```

## Event Queries

### Get Events

**GET** `/api/events`

Query all eBPF events with optional filtering and pagination.

**Authentication:** Required (Bearer token)

**Query Parameters:**
- `type` (optional, string): Filter by event type ("connection", "packet_drop", etc.)
- `program` (optional, string): Filter by program name
- `pid` (optional, integer): Filter by process ID
- `interface` (optional, string): Filter by network interface
- `since` (optional, RFC3339 timestamp): Events after this time
- `until` (optional, RFC3339 timestamp): Events before this time
- `limit` (optional, integer, default: 100): Maximum results
- `offset` (optional, integer, default: 0): Pagination offset

**Response (200 OK):**
```json
{
  "events": [
    {
      "id": "event_12345",
      "type": "connection",
      "program_name": "connection_tracer",
      "pid": 1234,
      "command": "curl",
      "src_ip": "192.168.1.100",
      "dst_ip": "8.8.8.8",
      "src_port": 54321,
      "dst_port": 443,
      "protocol": "tcp",
      "interface_name": "eth0",
      "interface_index": 2,
      "observed_at": "2025-02-09T07:47:30Z"
    }
  ],
  "total": 1524,
  "limit": 100,
  "offset": 0
}
```

**Response Fields:**
- `events` (array): List of event objects
  - `id` (string): Unique event identifier
  - `type` (string): Event type ("connection" or "packet_drop")
  - `program_name` (string): eBPF program that generated event
  - `pid` (integer): Process ID
  - `command` (string): Process command name
  - `src_ip` (string): Source IP address
  - `dst_ip` (string): Destination IP address
  - `src_port` (integer): Source port
  - `dst_port` (integer): Destination port
  - `protocol` (string): Protocol name ("tcp", "udp", "icmp", etc.)
  - `interface_name` (string, nullable): Network interface (e.g., "eth0")
  - `interface_index` (integer, nullable): Linux network interface index
  - `observed_at` (RFC3339 timestamp): When event was observed
- `total` (integer): Total matching events
- `limit` (integer): Query limit parameter
- `offset` (integer): Query offset parameter

**Examples:**

All events:
```bash
curl "http://localhost:8080/api/events?limit=10" \
  -H "Authorization: Bearer $TOKEN"
```

Connection events only:
```bash
curl "http://localhost:8080/api/events?type=connection&limit=10" \
  -H "Authorization: Bearer $TOKEN"
```

Packet drops from last hour:
```bash
curl "http://localhost:8080/api/events?type=packet_drop&since=$(date -u -d '1 hour ago' +%Y-%m-%dT%H:%M:%SZ)" \
  -H "Authorization: Bearer $TOKEN"
```

Events for specific process:
```bash
curl "http://localhost:8080/api/events?pid=1234" \
  -H "Authorization: Bearer $TOKEN"
```

Events on specific interface:
```bash
curl "http://localhost:8080/api/events?interface=eth0" \
  -H "Authorization: Bearer $TOKEN"
```

## Connection Events

### Get Connection Summary

**POST** `/api/connection-summary`

Retrieve aggregated statistics for connection events.

**Authentication:** Required (Bearer token)

**Request Headers:**
```
Content-Type: application/json
```

**Request Body:**
```json
{
  "interface": "eth0",
  "since": "2025-02-09T00:00:00Z",
  "until": "2025-02-09T23:59:59Z"
}
```

**Request Fields (all optional):**
- `interface` (string): Filter by network interface
- `since` (RFC3339 timestamp): Start time for summary
- `until` (RFC3339 timestamp): End time for summary

**Response (200 OK):**
```json
{
  "summary": {
    "total_connections": 1524,
    "unique_processes": 12,
    "unique_destinations": 45,
    "protocols": {
      "tcp": 1200,
      "udp": 300,
      "icmp": 24
    },
    "top_processes": [
      {
        "pid": 1234,
        "command": "chrome",
        "connection_count": 156
      }
    ],
    "top_destinations": [
      {
        "ip": "8.8.8.8",
        "port": 443,
        "connection_count": 89
      }
    ]
  }
}
```

**Response Fields:**
- `summary` (object):
  - `total_connections` (integer): Total connection events
  - `unique_processes` (integer): Number of unique processes
  - `unique_destinations` (integer): Number of unique IP:port pairs
  - `protocols` (object): Count by protocol
  - `top_processes` (array): Most active processes
  - `top_destinations` (array): Most contacted destinations

**Example:**
```bash
curl -X POST http://localhost:8080/api/connection-summary \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"interface":"eth0"}'
```

```json
      "observed_at": "2025-02-09T07:47:30Z"

  "offset": 0

```

**Examples:**

All connections:
```bash
curl "http://localhost:8080/api/list-connections?limit=20" \
  -H "Authorization: Bearer $TOKEN"
```

Connections from specific process:
```bash
curl "http://localhost:8080/api/list-connections?pid=1234" \
  -H "Authorization: Bearer $TOKEN"
```

TCP connections only:

## Packet Drop Events

### Get Packet Drop Summary

**POST** `/api/packet-drop-summary`

Retrieve aggregated statistics for packet drop events.

**Authentication:** Required (Bearer token)

**Request Headers:**
```
Content-Type: application/json
```

**Request Body:**
```json
{
  "interface": "eth0",
  "since": "2025-02-09T00:00:00Z"
}
```

**Request Fields (all optional):**
- `interface` (string): Filter by network interface
- `since` (RFC3339 timestamp): Start time for summary
- `until` (RFC3339 timestamp): End time for summary

**Response (200 OK):**
```json
{
  "summary": {
    "total_drops": 89,
    "drop_reasons": {
      "no_route": 45,
      "no_memory": 20,
      "invalid_header": 15,
      "acl_deny": 9
    },
    "affected_interfaces": ["eth0", "eth1"],
    "critical_drops": [
      {
        "reason": "no_memory",
        "count": 20,
        "severity": "high"
      }
    ]
  }
}
```

**Response Fields:**
- `summary` (object):
  - `total_drops` (integer): Total packet drop events
  - `drop_reasons` (object): Count by reason
  - `affected_interfaces` (array): Interfaces with drops
  - `critical_drops` (array): High-severity drop reasons

**Example:**
```bash
curl -X POST http://localhost:8080/api/packet-drop-summary \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"interface":"eth0"}'
```

### List Packet Drops

Retrieve detailed packet drop event records.

**Authentication:** Required (Bearer token)

**Query Parameters:**
- `reason` (optional, string): Filter by drop reason
- `interface` (optional, string): Filter by network interface
- `protocol` (optional, string): Filter by protocol
- `limit` (optional, integer, default: 100): Maximum results
- `offset` (optional, integer, default: 0): Pagination offset

**Response (200 OK):**
```json
{
  "drops": [
    {
      "id": "drop_12345",
      "reason": "no_route",
      "protocol": "ipv4",
      "src_ip": "192.168.1.50",
      "dst_ip": "10.0.0.1",
      "interface_name": "eth0",
      "dropped_count": 5,
      "observed_at": "2025-02-09T07:45:00Z"

  "total": 89,
  "limit": 100,
  "offset": 0
}
```

**Response Fields:**
- `drops` (array): List of packet drop events
  - `id` (string): Unique event identifier
  - `reason` (string): Why packet was dropped
  - `protocol` (string): Protocol version
  - `src_ip` (string): Source IP
  - `dst_ip` (string): Destination IP
  - `interface_name` (string): Network interface
  - `dropped_count` (integer): Number of packets dropped
  - `observed_at` (RFC3339 timestamp): When observed
- `total` (integer): Total matching events
- `limit` (integer): Query limit
- `offset` (integer): Query offset

**Examples:**

All packet drops:

## Error Responses

### Error Response Format

All error responses follow this format:

```json
{
  "error": "Error message describing what went wrong",
  "code": "ERROR_CODE",
  "details": {
    "field": "Additional context about the error"
  }
}
```

### HTTP Status Codes

| Status | Meaning | Example |
|--------|---------|---------|
| 200 | OK | Successful request |
| 400 | Bad Request | Invalid query parameters |
| 401 | Unauthorized | Missing or invalid token |
| 403 | Forbidden | Insufficient permissions |
| 404 | Not Found | Resource doesn't exist |
| 500 | Internal Server Error | Server error |

### Common Errors

#### 401 Unauthorized (Missing Token)
```json
{
  "error": "missing authorization header",
  "code": "MISSING_TOKEN"
}
```

#### 401 Unauthorized (Invalid Token)
```json
{
  "error": "invalid authorization header",
  "code": "INVALID_TOKEN"
}
```

#### 400 Bad Request (Invalid Timestamp)
```json
{
  "error": "invalid time format",
  "code": "INVALID_FORMAT",
  "details": {
    "expected": "RFC3339 timestamp format",
    "example": "2025-02-09T07:47:00Z"
  }
}
```

## Rate Limiting

### Rate Limit Headers

All API responses include rate limit information:

```
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 999
X-RateLimit-Reset: 1644398880
```

**Headers:**
- `X-RateLimit-Limit`: Maximum requests per hour
- `X-RateLimit-Remaining`: Requests remaining in current window
- `X-RateLimit-Reset`: Unix timestamp when limit resets

### Rate Limit Defaults

- **Global**: 1000 requests per hour
- **Per-user**: 100 requests per minute (if user-based limiting enabled)

### When Limit Exceeded

```
HTTP/1.1 429 Too Many Requests

{
  "error": "rate limit exceeded",
  "code": "RATE_LIMIT_EXCEEDED",
  "retry_after": 60
}
```

## Examples

### Complete Authentication Flow

```bash
#!/bin/bash

# 1. Login to get tokens
echo "Step 1: Logging in..."
LOGIN_RESPONSE=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user","password":"password"}')

ACCESS_TOKEN=$(echo $LOGIN_RESPONSE | jq -r '.access_token')
REFRESH_TOKEN=$(echo $LOGIN_RESPONSE | jq -r '.refresh_token')

echo "Access Token: $ACCESS_TOKEN"
echo "Refresh Token: $REFRESH_TOKEN"

# 2. Use access token to query programs
echo -e "\nStep 2: Getting programs..."
curl -s http://localhost:8080/api/programs \
  -H "Authorization: Bearer $ACCESS_TOKEN" | jq .

# 3. Get events
echo -e "\nStep 3: Getting events..."
curl -s "http://localhost:8080/api/events?limit=5" \
  -H "Authorization: Bearer $ACCESS_TOKEN" | jq .

# 4. Query connections
echo -e "\nStep 4: Getting connection summary..."
curl -s -X POST http://localhost:8080/api/connection-summary \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{}' | jq .

# 5. Refresh token when access expires
echo -e "\nStep 5: Refreshing token..."
REFRESH_RESPONSE=$(curl -s -X POST http://localhost:8080/api/auth/refresh \
  -H "Content-Type: application/json" \
  -d "{\"refresh_token\":\"$REFRESH_TOKEN\"}")

NEW_ACCESS_TOKEN=$(echo $REFRESH_RESPONSE | jq -r '.access_token')
echo "New Access Token: $NEW_ACCESS_TOKEN"
```

### Monitoring Network Interfaces

```bash
#!/bin/bash

TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user","password":"password"}' | jq -r '.access_token')

# Get events from specific interface
echo "=== Events from eth0 ==="
curl -s "http://localhost:8080/api/events?interface=eth0&limit=10" \
  -H "Authorization: Bearer $TOKEN" | jq '.events[] | {command, src_ip, dst_ip, protocol}'

# Get connection summary for interface
echo -e "\n=== Connection Summary for eth0 ==="
curl -s -X POST http://localhost:8080/api/connection-summary \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"interface":"eth0"}' | jq .

# Get packet drops for interface
echo -e "\n=== Packet Drops on eth0 ==="
curl -s "http://localhost:8080/api/list-packet-drops?interface=eth0" \
  -H "Authorization: Bearer $TOKEN" | jq '.drops[] | {reason, protocol, dropped_count}'
```

### Real-time Event Monitoring

```bash
#!/bin/bash

TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user","password":"password"}' | jq -r '.access_token')

# Poll for new events every 5 seconds
while true; do
  echo "=== Events (Last 5) ==="
  curl -s "http://localhost:8080/api/events?limit=5&type=connection" \
    -H "Authorization: Bearer $TOKEN" | jq '.events[] | {
      id,
      command,
      src_ip,
      dst_ip,
      dst_port,
      protocol,
      observed_at
    }'

  echo -e "\n--- Next update in 5 seconds ---\n"
  sleep 5
done
```
